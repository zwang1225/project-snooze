# Dog Dream Evolution Idle （狗子进化增量：梦境篇）

> Internal codename: **project-snooze**（repo 内部代号，不是产品名）。
> 产品正式名 **OPEN，未定**——想好之前文件夹和文档都用这个代号。
> Added 2026-10-22. Status: **spec 写到一半，慢慢拼**——已定的写在下面，
> 没想好的明确标 OPEN，不许当成已定方案往下开发。
> 待决定事项的进度表在同文件夹 `DECISIONS.md`，一个一个解决、解决一个划一个。

## Concept

像素风增量（idle / incremental）游戏：局外养一只你选定的狗当主角，
它睡着以后做梦——梦里它和一群好朋友一起进化成各种原创漫画式强力形态，
还能合体、挖隐藏。梦醒了回到现实吃喝拉撒、升级家当、培养感情，
再睡过去开下一场更强的梦。

## Why Try This

- 生产能力已不稀缺：生图（有现成美术平台）、写代码、做推广视频都能低成本做。
  稀缺的是命中一个产品——策略是多尝试、快验证、不行就砍。
- 增量品类本身开发便宜、美术需求低，适合一个人小步试。
- 狗 + 进化 + 收集是天然好传播的组合，进化截图有人愿意分享。
- 初步评分：5–6/10（有美术平台加分；分发和数值手感是主要风险，未验证）。
  等增量核心循环定了再重评。

## Distribution Thinking

- iOS 不是起点：App Store 无自然流量、审核慢。先网页版验证留存，再考虑套壳上 iOS。
- 品类有现成的免费冷启动口：r/incremental_games 社区、itch.io，
  以及自有短视频能力（进化过程本身就是短视频素材）。
- 图鉴收集 + 隐藏发现驱动玩家去 Reddit / 视频平台发帖讨论，是设计目标之一。

## 已定 (Decided)

### 美术

- 像素风，真小 sprite（约 96x96），每条进化线一套主色，颜色克制。
- 不做大尺寸“像素风插画”（AI 生成的假像素网格一眼假）。
- 形态拆件（身体 / 耳朵 / 装备 / 武器 / 光环分层），为合体做准备：
  合体 = 两只狗的部件 + 配色组合，不为每个组合重画整只。
- 进化只换装备 / 体型 / 光效，不换狗脸，保证认得出还是那只狗。
- 动画 2–4 帧即可；高阶形态靠发光 / 粒子显强。
- 角色全部原创（职业 / 神格原型），不用任何现成漫画 / 游戏 IP 角色。

### 核心动作（2026-10-23 定，D1.1）

- 核心就两个动词：**挖**和**闻**。挖出货，闻找货。
- 主货币 = 骨头，产出 = 狗在梦里刨坑挖出。
- 挖管提取：数量 / 品质 / 范围 / 深度都长在挖上；闻管发现：
  找货点、稀有货、朋友与隐藏都先要闻到。盲挖漏得多，鼻子越强漏得越少。
- 产速规矩：数字涨速与动画速度脱钩，刨的动作不变快（封顶）；
  变强体现在一刨出更多、挖得深骨头品质更高。
- 狗变多不属于核心产速，那是朋友系统（DECISIONS D3）。

### 玩家抉择（2026-10-23 定，D1.2）

- 双层抉择。快抉择 = 选点：闻出一轮味点后玩家选一个全队去刨——
  味浓土硬（大货慢）、味淡土松（快货少）、味怪（未知，可能朋友/材料/空），
  信息只给一半；任何味点不能永远最优，有最优解就是假抉择。
- 慢抉择 = 花 vs 埋：骨头花掉马上变强，或埋掉一段时间不能动，
  但生利息、招味引朋友（埋的细则随 D3/D5 展开）。
- 一局节奏：闻出味点 → 选一个 → 全队刨 → 出货 → 想花/埋 → 再闻下一轮。
- 自动化红线（D1.7 细化）：自动刨只能刨默认点，特殊味点必须玩家亲自选，
  不许自动化吃掉抉择。

### 产出结构（2026-10-23 定，D1.3）

- 分工克制：产出是全队在玩家选中的味点上合力刨，三条线各有所长——
  哈士奇（冰）蛮力：硬土、冻土、深层刨得动；
  博美（光）鼻子：闻得准、漏挖少、稀有货（金骨头等）靠它闻出；
  柴犬（影）怪味：味怪的点、夜里与藏起来的东西它擅长。
- 味点有类型，队伍配置对不对口直接影响产出；没有一条线能单养通吃，
  只养最强线会在另两类味点上吃瘪。
- 合体狗是双料精英：兼具父母两条线的长处 + 一个独有本事，
  是下场干活的顶级生产单位，不是站桩光环（定位细节见 DECISIONS D5）。

### 复杂度解锁顺序（2026-10-23 定，D1.7，v1 排班）

- 出场顺序：刨（开局单狗、单味点、只有骨头）→ 选点（鼻子变好，
  一次闻出多个味点才开始有选择）→ 朋友与分工（开始刷硬土/怪味点）→
  埋（第一次攒出像样的骨头之后）→ 深度与材料（第一层挖空下第二层）→
  首醒教学（第一场梦约 15–20 分钟、第一层挖完前后，半强制醒一次）→
  合体与图鉴谜语 → 自动刨（首醒后当升级，仍只刨默认点）。
- 原则：新系统一次只上一个；先让玩家遇上问题，再给解法。
- 数值形状、墙、随机份量不在纸上定案（DECISIONS D1.4–D1.6 改判玩测中定）。

### 主角与局外（现实世界）

- 主角 = 玩家在局外选定的那一只狗：品种自选，它就是主角，不会被重置掉。
- 局外是它的现实生活：吃喝拉撒、升级家当、养成、培养感情。
- 局外场景先做一间像素小屋，家当看得见地变好（梦会清空，家不会）：
  - 饭盆线：破碗 → 钢碗 → 自动喂食器 → 小厨房
  - 狗窝线：纸箱 → 垫子 → 小床 → 狗别墅
  - 玩具线：破布 → 球 → 会叫的鸭子 → 一箱玩具
  - 院子线：没院子 → 小院 → 花园 → 大草坪
- 局外有隐藏加成；醒来时的选择（吃啥 / 去哪玩 / 在哪睡）会影响下一场梦
  （跨局配方，见隐藏一节）。
- 局外阶段要短（目标约 1 分钟做完选择就睡），不做成第二个养成游戏。
- 梦境场景（D11 打包默认，用户改判）：v1 就多场景——草地起手，
  随进度与醒来选择 seed 出雪原 / 海边 / 城市等；各场景带倾向的朋友与隐藏
  （概率权重，非独占）；深度层与事件覆盖层继续叠加。
- 开局 5 分钟（D12 打包默认）：选品种 → 起名可跳过 → 首睡 → 60 秒首进化 →
  首味点亲选 → 首块高品质骨 → 埋一小笔 → 提示推不动就醒；教程只给情境提示。
- 技术与验证（D13/D14 打包默认）：原型单页 HTML + Canvas 2D + 原生 JS，
  存档 localStorage，美术先程序化像素占位；验证发 r/incremental_games +
  自有短视频，7 天催更/问隐藏信号定去留。

### 梦 / 醒循环（代替干巴巴的转生）

- 睡着（局内）：进化、合体、隐藏事件，攒局内资源；局内资源与货币细节 OPEN。
- 醒来（结算）：手动醒（D2 已定）——梦里持续攒局外成长资源（待结算，
  醒来才拿到手）；玩家在梦里推到推不动（撞墙、涨势停）时醒来，
  拿攒下的做局外升级，下一场梦推得更远。梦里形态按阶数折成局外
  成长资源（公式见 DECISIONS D10：总产出 ×（1 + 0.1 × 最高深度层）
  + 新图鉴 × 50 占位；< 3 分钟短梦只结算 20%），梦清空。
  本质是增量的 prestige / 转生，但叙事上天经地义，不让玩家心疼。
- 现实（局外）：花资源升级永久家当 + 做醒来选择。
  醒来名额（D9，2026-10-25 定）：限量，每醒一次选 3 件做；
  升级花钱不占格，3 格只给出门、互动这类花时间的活动；
  3 格 = 吃 1 格 + 玩 1 格 + 睡 1 格（吃 seed 梦的味，玩决定去哪，
  睡决定在哪睡）。
- 再睡着：带永久加成开新梦，梦的内容被醒来选择影响（seeded dream）。

### 交互反馈层（2026-10-25 定，D17；表现层，不改规则数值）

- 狗走位：闲时场景内溜达、停下闻地面；选中味点后跑向该点地面位置
  并在该处刨；味点在地面有颜色标记与选中圈。
- 刨坑反馈：前倾开刨 + 土粒飞溅 + 地面留坑（整场梦保留）+
  骨头从坑里弹出、划弧线飞向计数器。
- 骨头美术：四档程序化像素骨（普通骨 / 肉骨头 / 金骨头 / 化石骨），
  右下角骨头堆随数量长；档位只做视觉区分，不改经济。
- 点击反应：点狗 = 蹦一下 + 尾巴摇快一阵 + 爱心粒子；
  H02 暗计数保持原样。
- 醒来反馈：每次选择与升级立刻给确认句；HUD 同时显示狗名与阶段名。
- 不做：腿部行走循环帧、装备 / 光环独立动画、耳朵甩动、新规则新数值。

### 身体动画（2026-10-25 定，D19；代码变换，不新增美术）
- 挖：前倾 + 下蹲 + 收势回弹；走 / 跑：起伏与前倾随速度变、
  尾巴摇速随速度变；被摸：挤压式弹跳；闲置：呼吸起伏。
- 只用已有立绘 + 变换，不生成逐帧姿态图、不做腿部行走循环帧。
### 场景美术（2026-10-25 定，D18；先做草地 + 雪原）
- 两张 480×300 像素背景：`assets/scenes/meadow.png`、`assets/scenes/snowfield.png`，
  免费生图，风格与狗立绘统一、配色克制。
- 背景只铺底、偏素；狗、坑、味点、骨头、粒子画其上，地面交互区不许遮挡；
  加载失败回退现有纯色。
- 内容：草地加花草树（花丛、草叶、远景树木），雪原加雪松与雪地草叶；
  花草树只放远景与画面边缘，不进地面交互区。
- 海边 / 城市不在本条；海梦事件仍只是气味事件，不单独画海场景。

### 移动 + 自动 + 多级（2026-10-26 定，D21；MVP 先出看看）
- 移动：点哪走哪 + WASD / 方向键；味点变世界里的坑，
  走近 40px 内按刨；点狗仍是摸；手动操作关自动。
- 自动：首醒后 100 骨头一次买断（占位价）；开关每梦重置；
  自动只找普通坑，味怪永不自动。
- 多级：四线各 5 级，费用 100 × 当前级；狗窝 4 级 = 别墅，
  纸箱之神配方可兑现；升级仍不占醒来格。

### 进化触发（2026-10-23 定，D4）

- 靠经历：狗干它擅长的事攒经历，涨满自动进化，不花骨头。
- 低阶（1→3）纯经历，保证前期顺滑；高阶（3→4、4→5）每阶另加一件
  该线标志性事迹当门槛（冰线刨穿冻土 / 光线闻出金骨头 / 影线夜刨有获），
  事迹清单随图鉴内容逐线编。各阶时长与经历曲线玩测中定。

### 合体 (Fusion)

- 规则：合体不吞掉父母狗，两只还在，合体多生出一只新的
  （吞掉玩家会心疼、舍不得合）。
- 门槛（D5，2026-10-23 定）：阶数达标（明面 004 / 隐藏 005）
  + 这一对有过一件共同事迹（清单随内容逐对编）。不收材料门票，
  副产物只作收藏与事迹信物。合体狗在 v1 就是完全体、不再进化，
  自己的阶留到开发阶段二再议。
- 拼法规则（D8，2026-10-25 定）：合体按**合体那一刻爹妈的当前阶**拼，
  不按草案里写过的旧阶名字——图鉴公式里的父母名随 D8 定稿同步改写。
- 明面合体（图鉴给公式，004 阶可合）：

### 隐藏 (Secrets)

设计规矩（已定）：
- 深埋可以，但必须留线索（图鉴 ??? 格 + 谜语 / 成就提示）。

### 狗味原料池 (Dog-Flavor Mechanics Pool)

检验标准（已定）：把狗换成矿机 / 机器人，数字还能原样跑的，
就不算狗味，只能算换皮。以下原料用户已全部认可为候选，
具体怎么拼进核心循环 OPEN：

- **埋骨头** — 骨头埋下当时不能用，过段时间挖出变多；
  埋的动作还可能引来新朋友闻味找来。天然的“存起来涨利息”
- **刨坑** — 一群狗在梦里刨大坑，越刨越深，每层土埋的东西不一样
  （旧玩具 / 化石 / 前代神狗装备）。进度是真的一层层挖下去
- **闻** — 新朋友 / 新区域 / 新隐藏不是买来的，是闻出来的：
  闻到味，跟一段，才见到对方
- **疯跑 (zoomies)** — 随机爆发，全场产出短时间翻倍，狗全在乱窜
- **占地盘** — 梦里草地一块块闻过 / 标记过才算你的；
  地盘越大，能来的朋友越多

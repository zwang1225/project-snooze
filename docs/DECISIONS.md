## 待决定 (Open Decisions)

### D1 🔴 增量核心循环：怎么“增”
主货币是什么、谁产出、怎么产出；狗味原料池（埋骨头 = 存起来涨利息 /
刨坑 = 分层向下推进 / 闻 = 解锁新朋友与区域 / 疯跑 = 随机爆发 /
占地盘 = 扩张产能）拼哪几个当主机制、哪几个当调味。
**卡住：D2、D3、D5、D12 全部。第一个要解决的就是这个。**

D1 拆开是七个子问题（2026-10-22 讨论补入），不只是数值 + 设定。
**打法：divide and conquer——按下面顺序一次只解决一个，
后面的先用占位假设顶着（如“产出先按各产各的算”），轮到它时再细想；
若后面的结论推翻前面的，回头改那一条，不推倒整张表。**

解决顺序（按依赖排，谁被别人需要谁先）：
- 第 1 个 · D1.1 设定皮 ✅（2026-10-23 用户拍板）：核心就两个动词——
  **挖**和**闻**：挖出货，闻找货。主货币 = 骨头，产出 = 狗在梦里刨坑挖出；
  挖管提取（数量/品质/范围/深度），闻管发现（货点/稀有/朋友/隐藏）。
  这是名词表，后面所有讨论都用它说话
  “产出变快”的定义（2026-10-23 用户追问后厘清）：数字涨速与动画速度脱钩，
  刨的动作不变快（封顶）；单只狗变强只体现在 ① 一刨出得更多
  ② 挖得深、骨头品质更高（一根顶多根，看得见的差别）。
  **狗变多不算这里——那是找朋友的设定，归 D3，不许混进核心产速**
  “刨坑还能怎么涨”候选轴（2026-10-23 讨论，未定案）：
  数量（一刨出更多）/ 品质（骨头更值钱）之外还有——
  深度（层层往下：新土层、新出货、硬度门槛）/ 范围（一刨的坑面变大、连锁塌方开洞）/
  品类（不只骨头：装备、材料、玩具、梦花等副产物，接合体材料）/
  嗅觉（漏挖率下降、稀有出土率上升：土里有 100 根，菜狗只闻出 30 根）/
  内容（挖出沉睡的朋友、隐藏房间、化石与前代装备——这类涨的是内容不是数字）
- 第 2 个 · D1.2 玩家动作与抉择 ✅（2026-10-23 用户拍板）：**双层抉择**。
  快抉择 = 选点：闻出几个味点（味浓土硬的大货 / 味淡土松的快货 / 味怪的未知），
  信息只给一半，玩家选一个全队去刨，几十秒一次，管“手上有事干”；
  慢抉择 = 花 vs 埋：骨头花掉马上变强，还是埋掉生利息 + 招味引朋友，
  攒到一笔想一次，管长线纠结。成立条件：任何味点都不能永远最优
  （急用选快货、挂机选大货、怪味靠好奇），有最优解就是假抉择。
  一局节奏：闻出味点 → 选一个 → 全队刨 → 出货 → 花/埋 → 再闻下一轮
- 第 3 个 · D1.3 产出结构 ✅（2026-10-23 用户拍板）：**分工克制**。
  产出是全队在选中味点上合力刨（承 D1.2），三条线各有所长：
  哈士奇（冰）=蛮力，硬土/冻土/深层刨得动；博美（光）=鼻子，闻得准、
  漏得少、稀有货靠它；柴犬（影）=怪味与夜里/藏起来的东西。
  味点有类型，队伍配得对不对口影响产出——没有哪条线可以单养通吃。
  合体狗 = 双料精英：父母两条线的长处都有 + 一个独有本事，
  是真下场干活的生产单位，不是站桩加 buff 的光环（细则接 D5）
- 第 4 个 · D1.7 复杂度解锁顺序 ✅（2026-10-23 用户采纳为 v1 排班）：
  刨（开局单狗单味点）→ 选点 → 朋友与分工 → 埋 → 深度与材料 →
  首醒教学（第一场梦约 15–20 分钟，第一层挖完前后）→ 合体与图鉴谜语 →
  自动刨（首醒后当升级卖）。细节（首醒精确时机等）与 D2/D12 联动时再调
- 第 5 个 · D1.4 数值形状 🎮 改判“玩测中定”（2026-10-23）：形状方向
  （先快后慢、指数滚雪球）先按 genre 常规占位，初始值直接写进原型，
  靠真玩调，不在纸上拍
- 第 6 个 · D1.5 墙 🎮 同上，玩测中定：先按“每阶进化前一道墙”的
  常规占位进原型，位置和高度靠玩测挪
- 第 7 个 · D1.6 随机与惊喜 🎮 同上，玩测中定：暴击/疯跑/出货波动
  先给保守占位（低频小幅），玩测觉得太平再加

### D2 ✅ 一场梦的结构（2026-10-23 用户拍板）
**手动醒。** 睡觉时就在攒局外成长用的增量（待结算，醒来才拿到手）；
玩家自己判断：在梦里继续推，推不动了（撞墙、涨势停了）就醒来，
把攒下的拿去做局外升级，下一场梦推得更远。局外迭代就靠这个循环。
不需要防拖机制：推不动时增量自然不再涨，拖着没收益，墙就是闹钟。
结算折算公式归 D10，首醒教学时机已在 D1.7 排班里。

### D3 🔴 朋友系统
已定方向（2026-10-23）：朋友先只考虑**局内遇见**（不走购买、不走局外带进），
带随机性、有 roguelite 性质——每场梦遇见谁不完全可控，有欧有非。
“挖到朋友”（从土里刨出狗）被否：土里没有狗，不成立。
遇见渠道已定（2026-10-23 用户全数采纳）：主渠道 = 闻味跟踪
（顺味跟到草地边/雾里遇见；设定：梦境草地是公共的，所有睡着的狗都来，
每场梦访客池随机，这就是 roguelite 随机性的来源）；
随机事件池 = 刨坑围观 / 埋骨头味招来访客 / 救助（卡住的，刨开环境）/
疯跑撞见 / 树叶堆里睡着的（刨叶子不刨土，唯一成立的“挖出来”）。
朋友去留已定（2026-10-23 用户拍板，比 B 方案更进一步）：
**默认留不下来**——梦里遇见的朋友醒来就散，只记图鉴（记得你、认你的味，
下场梦可能再遇）。例外通道：达到特定条件后，能在**局外（现实）见到
这只狗**，它成为现实里的狗子朋友（可以和你一起的永久伙伴，局外能养、
梦里可靠入队）。“梦见过 → 现实里真遇见 → 成为家人”是长期追逐目标，
条件清单待定（下一条单聊）。
留下的条件框架已定（2026-10-23）：**两段钥匙**。
第一段（梦里）缘分攒够：重逢次数让图鉴里它的页面逐步变清
（剪影 → 长相 → 习性 → 它专属的一件心愿小事，如陪它埋够骨头 /
救过它 / 替它收着信物），把心愿了了；第二段（局外）去对地方：
图鉴给一句它常出没之地的提示，醒时选对活动（公园 / 夜路 / 收容所…）
才有机会真遇见，次数带随机。第一只永久朋友保底简单
（最早反复遇见的那只，重逢 3 次 + 去一次公园量级），教玩家这条路存在；
后面的逐只变难、故事逐只加厚。具体哪只狗配哪件小事是内容活，做图鉴时逐只编。
**狗子名单是固定的**（2026-10-23 用户定）：出现的狗都是预先写好的
固定角色，各有故事；随机只在“今晚先遇见谁、什么时候遇见”，不是随机生成狗。
**由此产生通关条件**（2026-10-23 用户点出）：固定名单全员都在现实里
遇见、住进来 = 通关（增量游戏少有明确结局，这是差异化）；
通关演出与通关后（继续玩 / 更深的梦）待定，另开一条。
狗位与名单规模已定（2026-10-23）：**章节制**——第一章固定名单 10 只
（三条线约 3/3/4 分），10 只全接回家 = 第一章通关；后续章节逐批加狗，
总名单扩到 20+，每批都是新故事 + 更新话题。三个数分开管：
名单总数（章节决定）/ 家里容量（开局主角 +1~2，靠院子与房子升级扩，
终局盖满本章名单，想接下一只先得有地方住）/ 梦里同行（表现层，
约 8–10 只封顶，再多糊成一团，具体玩测调）。
至此 D3 全部子项已定（遇见渠道 / 去留 / 两段钥匙 / 固定名单 /
通关 / 章节与容量）。朋友和主角的产出分工已由 D1.3 分工克制回答。
**“狗变多”整体归本条**（总产出随狗数涨只是它的结果，不是 D1 的产速机制；
2026-10-23 用户纠正并厘清边界）。

### D4 ✅ 进化触发与数值节奏（2026-10-23 定触发，节奏玩测中定）
**触发 = 经历**：狗跟着队伍刨、闻、干它擅长的事攒经历，涨满自动进化
——进化是“长大了”，不是买来的，不花骨头（骨头只走经济循环）。
分层：低阶（1→3）纯经历自动长，保前期顺滑（60 秒首进化）；
高阶（3→4、4→5）每阶加一件该线标志性事迹当门槛
（例：冰线刨穿过一次冻土层 / 光线亲手闻出过一根金骨头 /
影线夜里刨到过一次东西），成神之前先干成一件像样的事。
事迹具体清单随图鉴内容逐线编（内容活）。
数值节奏（各阶时长、经历曲线、离线收益给多少/上限）按总原则玩测中定，
草案时长（1 分钟 / 5 分钟 / 30 分钟 / 3 小时 / 1 天）作原型占位。

### D5 ✅ 合体细节（2026-10-23）
**门槛：阶数 + 共同事迹**——明面合体两只到 004 阶、隐藏合体到 005 阶
（承原草案），且这一对必须一起干成过一件事（一起刨穿某层 /
一起熬过流星夜 / 一起完成救助之类，共同事迹清单随内容逐对编；
隐藏合体的谜语条件算事迹的一种）。
不收材料门票：梦花、化石等副产物只做图鉴收藏与个别事迹的信物，
不当通用合体货币，免得合体被刷料绑架。
合体定位（D1.3）：双料精英生产单位，不是光环。
**合体狗再进化：阶段一（v1）不做**——合体合出来就是完全体；
要不要给合体狗自己的阶，开发阶段二再议。

### D7 ✅ 局外感情系统（2026-10-23）
**定调（用户）：不靠催回来——东西做得好，玩家自己会回来。**
- **不衰减**：感情攒下就是攒下了，不掉、不用维护；
  没有每日喂食打卡、没有登录 streak 这类逼回机制。
- **涨法 = 真投入**：花的时间和精力本身就是感情——一起做的梦、
  一起干成的事（事迹）、为它花的选择（喂什么、去哪、了却心愿），
  这些经历累积成感情；不靠重复签到式动作刷。

  **红线：感情不做产出倍率**——一旦变成效率数值，玩家会算账刷它，
  “不逼回来”的定调就从内部破了。

### D17 ✅ 交互反馈层（2026-10-25，用户纠正：先改 spec 再动手）
立项原因：MVP 1 + 真图版实测结论——循环转得动、数值算得对，
但玩家体感是“0 interaction”：狗站桩、刨坑只变数字、骨头只变数字、
点击没反应。美术对了不等于可玩；交互反馈是 MVP 的必备层，
不是 polish。本条先于实现 PR 落 spec，实现 PR（interaction-pass）
须按本条复核，spec 改了实现跟着改。

原则（按优先级）：
① 每个玩家动作在场景里立刻有可见反馈，不只变数字、不只写日志；
② 狗永远在 visibly 干点什么（闲逛 / 跑向目标 / 刨 / 被摸反应），
   不许长时间站桩当贴图；
③ 反馈层级：场景 > HUD > 日志——关键信息不许只出现在页面底部日志里；
④ 不改任何规则数值：本条只管表现层，XP、产出、冷却、结算公式全不动。

本层行为（v1 范围）：
- 狗走位：闲时在场景内左右溜达、停下闻地面；选中味点后跑向该点
  的地面位置并在该处刨；味点在地面有颜色标记与选中圈。
- 刨坑反馈：前倾开刨 + 土粒飞溅 + 地面留坑（整场梦保留，上限 24 个）
  + 骨头从坑里弹 出、划弧线飞向计数器。
- 骨头美术：四档程序化像素骨（普通骨 / 肉骨头 / 金骨头 / 化石骨，
  颜色与形状区分），右下角骨头堆随数量长；档位映射只做视觉区分，
  不改经济规则。
- 点击反应：点画面上的狗 = 开心蹦一下 + 尾巴摇快一阵 + 爱心粒子；
  H02 暗计数保持原样（反应叠加其上，不替代）。
- 醒来反馈：每次吃 / 玩 / 睡选择与每次升级立刻给确认句
  （选了什么、带来什么），不只按钮变灰；不新增家当美术。
- HUD 命名：同时显示狗名与阶段名（如“博美 · 001 奶团子”），
  不再只显示阶段名。

本层明确不做（留后续）：
- 腿部行走循环帧（走位只靠位置 + 起伏 / 前倾表现）；
- 装备 / 光环层独立动画（已 baked 进立绘，不重影叠加）；
- 耳朵甩动（无耳朵分层，做不了）；
- 新经济规则、新数值、新内容（朋友、更深的层均不在本层）。

验收（自测门槛，助理自测、不推给用户）：
- 狗会动（闲逛 + 跑向味点）、刨看得见（土 + 坑 + 飞骨）、
  骨头看得见（四档 + 骨头堆）、点狗有反应、醒来每次选择有确认句。
  五项缺一，本层不算完。

### D18 ✅ 场景美术（2026-10-25，用户定范围：先做已上线的两张）
立项原因：场景至今只有两块纯色（草地浅绿、雪原浅蓝白），
实测判“雪原只是换了个底色”。场景美术是 D11 多场景的落地点，
但本条只做已上线、可玩的两个场景，不提前画未进游戏的海边 / 城市。

范围：
- 草地（meadow）：梦境草地，起手场景；
- 雪原（snowfield）：首醒后解锁。
- 海边 / 城市：不在本条，D11 清单细化、场景进游戏时再另立条目。

规格（动手前定死）：
- 风格：像素风，与狗立绘（96×96 程序化像素占位起家、后换真像素图）
  同一克制配色路子，不做写实插画；
- 尺寸：铺满 480×300 画布的背景图，`assets/scenes/meadow.png`、
  `assets/scenes/snowfield.png`；
- 生成渠道：默认内置免费生图（$0），与狗美术同一规矩；
  付费生成先报价、用户当轮批准才跑；
- 可读性底线（D17 的延伸）：背景只铺底、偏素，狗、坑、味点标记、
  骨头堆、粒子一律画在背景之上；地面交互区（狗走位、味点、坑）
  不许有抢眼的景物遮挡；背景加载失败回退现有纯色，不许空白或破图。

内容方向（细化由生图 prompt 落，不在这里脑补死）：
- 草地：远景柔和天空 + 云、远景树木、花草点缀（花丛、草叶），

- 雪原：雪地 + 远处雪松（树）、雪地草叶点缀、冷色调，
  地面交互区同样留白。
- 摆放规矩：花草树只放远景与画面边缘，绝不进地面交互区
  （狗走位、味点、坑的位置），可读性底线优先于景物丰富度。
- 海梦事件仍只是草地上的气味事件，不单独画海场景。

验收（助理自测）：
- 两张背景在 Pages 上铺满画布、无拉伸变形、无遮挡；
- 切换草地 / 雪原即时生效；断图时回退纯色；
- 狗、坑、味点、骨头在背景上全部一眼看清。

### D19 ✅ 身体动画（2026-10-25，用户定：效果调优 + 身体动画都要）
立项原因：肉眼验结论——D17 效果调优（PR #9）只能让反馈更显眼，
狗本身仍是同一张站姿贴图：挖、走、被摸全是同一个姿态，
“活过来”缺的是身体动作。本条补身体动作，但仍走代码动、
不动逐帧画法：用已有立绘 + 变换（缩放 / 前倾 / 起伏 / 摆动）做动作，
不生成新姿态帧——逐帧 AI 生成会跑偏（脸 / 尾巴每帧不一致），
这是 2026-10-25 用户点出的动画担忧。

本层行为（v1 范围，全是变换、不新增美术文件）：
- 挖：刨的瞬间身体前倾 + 下蹲（纵向压扁 + 向前倾角），
  配土粒飞溅，收势回弹；
- 走 / 跑：起伏幅度随速度变（跑比闲逛起伏大、前倾更多），
  尾巴摇速随速度变；
- 被摸：挤压式弹跳（先压扁后回弹）+ 轻微仰头倾角；
- 闲置：呼吸起伏（缓慢纵向缩放），狗永不完全静止。

明确不做（留后续）：
- 腿部行走循环帧、逐帧姿态图（挖姿 / 走姿 / 开心脸单张）；
- 新规则、新数值、新内容。

验收（助理自测，不推给用户）：
- 正常游玩速度下，挖 / 走 / 跑 / 被摸 / 闲置五种状态
  各自一眼可辨，不再是同一张贴图平移；
- 变换不遮挡、不穿帮（狗不超出画布、不压住味点与坑）。

占位与验收：以上数值全是占位，玩测中调；验收（助理

框与地图：

- 场景切换（草地 / 雪原）做成框内标签。

### D24 ✅ 手机竖屏响应式（2026-10-26，用户手机截图纠正）
起因：D23 上 Pages 后用户手机截图——竖屏下 HUD 占了半框、
动作条底部被裁、狗和场景被面板盖住，配文“完全没有
responsive lol”。根因：框按宽度缩放（max-width 100%），
而 DOM 叠层的字号、内边距是固定 14px / 6px 不缩放；8/5 的
矮框在竖屏手机上只有约 225px 高，根本装不下两层叠层。

改法（只改布局，不改规则与 JS）：
- 画布 + 边缘箭头 + 进化横幅包进一层 #stage（桌面端
  #stage 仍是铺满框的绝对层，位置口径不变）。
- 窄屏（≤640px）media query：框取消 aspect-ratio、高度随
  内容走；#stage 变相对层，画布按 8/5 铺满宽度在上；HUD
  与底部动作条变静态块叠在画布下方，页面滚动；字号、
  按钮内边距略缩小；进化横幅改贴画布顶部。
- 桌面端 960 框内叠层布局原样不动；覆盖面板（醒来 / 图鉴 /
  玩法 / 日志 / 重开）仍是框内绝对层，竖屏下盖住整段堆叠
  内容。

验收：手机竖屏打开能看到完整画布、HUD、全部按钮，不裁切。
诚实说明：我方无真机，只做结构校验（标签闭合、选择器与
元素对应、JS 零改动）；手机上的最终验收以用户实测为准。

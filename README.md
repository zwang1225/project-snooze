# project-snooze — 原型 MVP 1

像素风增量游戏原型：局外选一只狗当主角，睡着做梦（挖 + 闻、选点、花 vs 埋、
靠经历进化），手动醒来结算，醒时升级家当 + 吃 / 玩 / 睡各选 1 件，再睡开下一场梦。

## Spec 在哪

设计决策的 source of truth 不在这个 repo，而在 idea-os 的
`ideas/project-snooze/`（`SPEC.md` + `DECISIONS.md`，D1–D14 已锁）。
本原型只实现，不重新设计；凡是 spec 里标“占位 / 玩测调”的数值，
这里直接用占位值。

## 怎么跑

不需要构建，不需要装任何东西：

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000/ 。也可以直接双击打开 `index.html`
（存档用 localStorage；`file://` 下部分浏览器会限制 localStorage，
推荐用上面那条命令起本地服务器）。

## 玩法（MVP 切片，D14）

- 选品种：博美（光线 · 鼻子）/ 哈士奇（冰线 · 蛮力）/ 柴犬（影线 · 怪味）；
  起名可跳过，默认用品种名。
- 梦里：按“闻一闻”闻出 3 个味点（味浓土硬 = 大货慢、味淡土松 = 快货少、
  味怪 = 未知），选一个全队去刨；每秒产出三档大致相等，没有永远最优解。
- 花 vs 埋：花 20 根骨头 → 本梦刨力 +1；埋 10 根 → 60 秒后挖出变多（+30%，
  原型缩短时长，占位）。
- 进化：靠经历自动进化，不花骨头；001→002 需 150 经历（约 60 秒内首进化），
  002→003 需 600；MVP 上限 003 阶。
- 深度：只做第一层（300 根挖空）；第二层显示为锁定，不做更深的层。
- 手动醒：结算 = 梦里总骨头产出 ×（1 + 0.1 × 最深层）+ 新图鉴 × 50；
  不到 3 分钟的短梦只结算 20%；首醒教学奖励 +100 只发一次。
- 醒着：花结算资源升级四条线（饭盆 / 狗窝 / 玩具 / 院子，MVP 每线升 1 级，
  不占醒来名额），再吃 1 格、玩 1 格、睡 1 格，然后睡过去。
- 图鉴：至少一条谜语（???：它在你一直点它的时候出现）。
- H02 乱码狗 ERROR.PUP：点同一只狗满 999 次后，每次点击有 1% 概率触发
  （占位概率），触发后狗显示花屏错位变体并记入图鉴。
- 场景：草地起手；第一次醒来后解锁雪原（调色 + 背景变体，附倾向说明）。
- 跨局配方（四个全进 v1）：三文鱼连吃 3 次 → 下场梦海梦事件；
  院子同角落连转 3 次 → 梦花；公园疯跑 → 夜里影子预告（湿脚印 + 图鉴一笔，
  H03 本体收服留后续版本）；纸箱之神需狗别墅，MVP 狗窝最高只到垫子，
  故仅记连选进度、不兑现。
- 流星夜：每场梦 15% 概率，前 10 分钟全场产出翻倍。

## 存档与 Steam 预留（D13 硬约束）

所有持久化只走 `js/storage.js` 的 `StorageAdapter` 接口（load / save / clear），
v1 后端是 localStorage。游戏逻辑里不直接碰 localStorage 或任何浏览器专属 API，
以后裹 Electron / Tauri 上 Steam 时，只需换掉这个适配器（文件存档 / Steam Cloud）。

## 刻意没有的东西（按 spec）

- 没有衰减、没有每日签到、没有登录 streak：感情不靠催回来。
- 没有付费内容、没有付费美术：sprite 全部是代码画的程序化像素占位（$0）。
- 没有离线收益：MVP 不做离线结算。

## 已知占位 / 未实现（诚实清单）

- 数值（XP 需求、产出、埋 60 秒、1% 乱码概率、15% 流星夜）均为占位，玩测调。
- H04 闪光金狗：spec 要求“领新狗时”触发，MVP 没有领新狗流程，故未实现。
- H01 / H03 本体 / 挖洞事件：按 D6 推迟，不在 v1。
- 合体 F01：MVP 上限 003 阶，达不到 004 阶合体门槛，故未实现；图鉴谜语位已留。
- 自动刨：按 D1.7 排班在首醒后当升级卖，MVP 未做（手动刨是核心手感验证点）。
- 朋友系统（D3 两段钥匙、固定名单 10 只）：MVP 只有场景倾向说明与配方影子，
  完整朋友遇见 / 留下流程未实现。
- 第二层及更深的层、雪原之外的场景（海边 / 城市）：未实现。
- 埋骨头“招味引朋友”：MVP 只实现利息，招朋友部分未接。
